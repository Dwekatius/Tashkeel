# Tashkeel

Arabic diacritization project built around CATT EO, with:
- v3 balanced checkpoint backup
- v4 punctuation-aware training/eval/runtime track
- local web UI tooling
- dataset prep, training, and evaluation scripts

This repository is being used as a private backup snapshot of the working
project.

Notes:
- Large model artifacts are stored with Git LFS.
- Portable packaged app folders are intentionally excluded from Git.
- `handover.txt` is the main project state file to read first.
