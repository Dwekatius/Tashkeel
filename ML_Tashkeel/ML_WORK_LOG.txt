Created: 2026-04-24

Purpose
-------

This folder is the standalone university-project workspace for the ML
punctuation restoration stage.

The main product model, CATT v4, already preserves punctuation when punctuation
exists in the input. It does not generate missing punctuation from scratch.
Therefore the new ML task is intentionally narrow:

  input plain Arabic words
  -> predict punctuation after each word
  -> reconstruct a punctuated Arabic text
  -> pass that text into the existing v4 tashkeel model

Architecture
------------

The punctuation model is formulated as word-boundary sequence labeling.

For every Arabic word, predict exactly one label for what should appear after
that word:

  NONE
  COMMA
  PERIOD
  QUESTION
  COLON
  SEMICOLON
  EXCLAMATION

This is safer than sequence-to-sequence generation because the model is not
allowed to rewrite, delete, or invent Arabic words. It can only choose boundary
punctuation labels.
