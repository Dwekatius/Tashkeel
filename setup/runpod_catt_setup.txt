RunPod Setup — Fine-tune CATT EO on our tashkeel dataset
=========================================================

WARNING: This is NOT the Qwen/Unsloth flow. CATT is a custom PyTorch Lightning
encoder (not an HF LLM), so Unsloth does not apply. Plain PyTorch only.

GPU configs:
  RTX 6000 Pro (96 GB):  batch 16  num_workers 8   (fits comfortably with bf16)
  H100 (80 GB):          batch 16  num_workers 8
  A100 (80 GB):          batch 16  num_workers 8
  5070 Ti / consumer:    batch 8   num_workers 4   (and use precision="16-mixed")

Pod image:
  Use any PyTorch 2.x image. The RunPod "PyTorch 2.4" template works.
  (Unsloth image is fine too — we just won't use it.)

Expected training time on RTX 6000 Pro:
  ~50 min/epoch on 168k rows, so 10 epochs ≈ 8 hours.
  Cut epochs to 3–5 for a first run to see if val_der is moving.


Upload dataset to /workspace/
-----------------------------
  1. Locally zip the catt_dataset folder (PowerShell):
       cd "<project>"
       Compress-Archive -Path catt_dataset -DestinationPath catt_dataset.zip -Force

  2. Zip the finetune script too:
       Compress-Archive -Path setup/catt_finetune.py -DestinationPath catt_finetune.zip -Force

  3. Upload BOTH zips via RunPod file manager to /workspace/.

  4. On pod, unzip and verify:
       !cd /workspace && unzip -o catt_dataset.zip && unzip -o catt_finetune.zip
       !wc -l /workspace/catt_dataset/train/train.txt /workspace/catt_dataset/val/val.txt
     Must show:

        16220 /workspace/catt_dataset/val/val.txt
     If counts differ → re-upload via zip. Drag-and-drop corrupts large Arabic
     files silently, same as with the Qwen run.

%cd /workspace/catt
!python -c "
import torch
from tashkeel_tokenizer import TashkeelTokenizer
from eo_pl import TashkeelModel
tok = TashkeelTokenizer()
m = TashkeelModel(tok, max_seq_len=1024, n_layers=6, learnable_pos_emb=False)
m.load_state_dict(torch.load('models/best_eo_mlm_ns_epoch_193.pt', map_location='cpu'))
m.eval().to('cuda')
with open('dataset/val/val.txt', encoding='utf-8') as f:
    lines = [l.strip() for l in f if l.strip()][:200]
# strip tashkeel for input
import re
strip = re.compile(r'[\u064B-\u0652\u0670]')
plain = [strip.sub('', l) for l in lines]
pred = m.do_tashkeel_batch(plain, batch_size=32, verbose=False)
# crude char-match score just to prove it's alive
print('sample pred[0]:', pred[0])
print('sample ref [0]:', lines[0])
"

Troubleshooting
---------------

• "Train: 97764" or lower line count after unzip → drag-and-drop truncation.
  Delete /workspace/catt_dataset and re-upload the zip.

• "No module named 'pytorch_lightning'" → pip install pytorch-lightning==2.5.2
  (CATT uses PL 2.5.2 API; older versions break ModelCheckpoint kwargs).

• onnxruntime-gpu wheel not available for this CUDA → remove it from
  requirements.txt (we don't need it for training, only for ONNX export).

• OOM on first step → drop BATCH_SIZE in catt_finetune.py to 8.

• OOM on later step but not first → lower max_seq_len to 768 (most rows
  are well under this — confirmed from training set stats).

• val_der not improving after 2 epochs → LR too high. Drop LR to 5e-6.
  If still flat → the pretrained checkpoint is already near our data's
  ceiling; consider training the ED variant instead (better accuracy,
  slower inference).

• "CUDA error: device-side assert" with Arabic char out of vocab →
  a non-Arabic char slipped through. Re-run prepare_catt_data.py locally
  and re-upload — clean_for_catt() filters everything but CATT's allowed set.
